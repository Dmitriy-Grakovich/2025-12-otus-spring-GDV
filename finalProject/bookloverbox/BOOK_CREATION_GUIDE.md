# Руководство по добавлению книг в BookLoverBox

## 📚 Кто может добавлять книги

Добавлять книги могут пользователи со следующими ролями:
- **Автор** (ROLE_AUTHOR)
- **Модератор** (ROLE_MODERATOR) 
- **Администратор** (ROLE_ADMIN)

## 🎯 Как добавить книгу

### Через веб-интерфейс:

1. **Войдите в систему** под учетной записью автора/модератора/администратора
2. Перейдите в раздел **"Мои книги"**
3. Нажмите кнопку **"Добавить книгу"**
4. Заполните форму с информацией о книге
5. Нажмите **"Создать книгу"**

### Через API:

```bash
POST /api/books
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN

{
  "title": "Мастер и Маргарита",
```

## 📋 Поля формы

### Обязательные поля (*)

| Поле | Описание | Пример |
|------|----------|--------|
| **Название** | Точное название книги | "Мастер и Маргарита" |
| **Автор** | ФИО автора | "Булгаков, Михаил Афанасьевич" |
| **Жанр** | Выбор из списка | Классическая литература |

### Рекомендуемые поля

| Поле | Описание | Пример |
|------|----------|--------|
| **Описание** | Аннотация книги | "Роман о дьяволе..." |
| **Теги** | Ключевые слова через запятую | "мистика, сатира, классика" |
| **Формат файла** | FB2, EPUB, PDF, MOBI, TXT | "EPUB" |
| **Год издания** | Год публикации | 1967 |
| **Возрастной рейтинг** | 0+, 6+, 12+, 16+, 18+ | "16+" |

### Дополнительные поля

| Поле | Описание | Пример |
|------|----------|--------|
| **Язык** | Язык текста книги | "Русский" |
| **Издательство** | Название издательства | "Художественная литература" |
| **Страниц** | Количество страниц | 384 |
| **URL обложки** | Ссылка на изображение | "https://..." |
| **Правообладатель** | Кто владеет правами | "Общественное достояние" |
| **ISBN** | Международный номер | "978-5-17-123456-7" |

## 🎨 Форматы файлов

Поддерживаемые форматы:
- **FB2** - FictionBook 2.0 (рекомендуется для художественной литературы)
- **EPUB** - Electronic Publication (универсальный формат)
- **PDF** - Portable Document Format
- **MOBI** - Mobipocket (для Kindle)
- **TXT** - Plain Text
- **RTF** - Rich Text Format
- **DOCX** - Microsoft Word

## 🏷️ Работа с тегами

### Правила создания тегов:

1. **Используйте через запятую**: `мистика, сатира, классика`
2. **Максимум 10 тегов** на книгу
3. **Используйте существительные**: `магия`, `путешествия`, `детектив`
4. **Избегайте дублирования жанра**: если жанр "Фэнтези", не добавляйте тег "фэнтези"

### Примеры хороших тегов:

- **Для фэнтези**: `магия, драконы, эльфы, приключения`
- **Для детектива**: `расследование, убийство, полиция, триллер`
- **Для романа**: `любовь, отношения, семья, драма`
- **Для научной фантастики**: `космос, будущее, технологии, роботы`

## 🔄 Статусы книги

После создания книга проходит следующие статусы:

1. **DRAFT** (Черновик) - книга создана, но не отправлена на модерацию
2. **MODERATION** (На модерации) - книга отправлена на проверку модератору
3. **PUBLISHED** (Опубликована) - книга одобрена и доступна всем пользователям
4. **REJECTED** (Отклонена) - книга отклонена модератором

## ✅ Рекомендации

### Для качественного описания:

1. **Название**: Используйте точное название, как в оригинале
2. **Автор**: Формат "Фамилия, Имя Отчество" для русских авторов
3. **Описание**: 
   - Напишите интригующую аннотацию (100-500 символов)
   - Не раскрывайте концовку
   - Укажите ключевые темы и настроение
4. **Теги**: Добавьте 3-7 релевантных тегов
5. **Обложка**: Используйте качественное изображение (минимум 300x400px)

### Что НЕ стоит делать:

❌ Оставлять пустое описание  
❌ Использовать слишком много тегов  
❌ Указывать неправильный жанр  
❌ Добавлять спойлеры в описание  
❌ Использовать нецензурную лексику в описании

## 📞 Поддержка

Если у вас возникли вопросы или проблемы с добавлением книги:
1. Проверьте, что вы вошли под учетной записью с правами автора
2. Убедитесь, что заполнены все обязательные поля
3. Проверьте формат данных (год - число, жанр - выбран из списка)
4. Обратитесь к администратору системы
