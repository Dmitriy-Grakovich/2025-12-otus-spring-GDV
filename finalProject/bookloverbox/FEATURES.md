## 🔄 Процессы и логика

### Жизненный цикл книги:
```
1. Автор создает книгу
   ↓
2. Статус: MODERATION (автоматически)
   ↓
3. Модератор проверяет:
   - Может отредактировать описание
   - Выбирает действие:
     ✓ Опубликовать → PUBLISHED (видна всем)
     ← В черновики → DRAFT (видна только автору)
   ↓
4. Опубликованные книги:
   - Отображаются в каталоге
   - Доступны для просмотра
   - Можно оставлять отзывы
```

### Роли и права доступа:

**READER (Читатель):**
- Просмотр каталога книг
- Просмотр детальной информации
- Добавление отзывов

**AUTHOR (Автор):**
- Все права читателя +
- Создание книг
- Просмотр своих книг
- Удаление своих книг

**MODERATOR (Модератор):**
- Все права автора +
- Просмотр книг на модерации
- Модерация книг (публикация/отклонение)
- Редактирование описания книг

**ADMIN (Администратор):**
- Все права модератора +
- Просмотр статистики
- Управление пользователями
- Управление жанрами
- Экспорт данных
